2. Login/signup
3. Dashboard
4. Create project
5. Requirements
6. 2D floor plan
7. Basic 3D view
8. Save project

If time remains:
- export
- share
- advanced automatic generation
- multilingual UI
- more detailed 3D

Do not sacrifice the planner for optional features.
